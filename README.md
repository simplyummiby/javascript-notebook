# JavaScript Notebook

A lightweight, mobile-friendly learning companion for the [freeCodeCamp JavaScript V9 course](https://www.freecodecamp.org/learn/javascript-v9).

## Features

- **Reference** — search JavaScript variables, string syntax, and methods; bookmark favorites; mark material as covered.
- **Practice** — short quizzes based **only on entries you mark covered**.
- **Playground** — safely experiment with string methods and see the expression and result.
- **Local progress** — favorites and covered states saved to your browser using `localStorage`.

No React, Supabase, server, build, or package installation needed. The website is a single `index.html` file.

## Publish on GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main**, **/(root)**, then **Save**.
4. GitHub Pages will publish the website at **https://simplyummiby.github.io/javascript-notebook/** after deployment completes.

## Study note

Start by marking only the material you've reached in freeCodeCamp as **Covered**. This keeps practice questions aligned with your learning. The reference is deliberately a beginner subset, not a complete transcription of the course.

## Local preview

Open `index.html` in a browser. There are no dependencies.

## Privacy

No accounts or analytics. Your favorites and covered topics are stored in the current browser, and do not automatically sync between devices. Clearing site storage removes them.
